# niri 快捷键速查

> `Mod+/` 随时呼出本页（浮动 kitty + bat）。
> `Mod+Shift+/` 是 niri 自带的「重要快捷键」浮层，内容更少，两个可以互补。
>
> **Mod = Super（Win 键）**。在 niri 里 `Mod` 是特殊修饰键：跑在 TTY 上等于 Super，
> 跑在窗口里（winit）等于 Alt。
>
> 配置来源两份，都在 `~/.config/niri/`：
>
> - `base.kdl` —— 由 niri 自带 `default-config.kdl` 生成（Nix 管理，随 niri 升级自动更新）
> - `config.kdl` —— 仓库 `dotfiles/niri/config.kdl`（软链，保存即热重载）
>
> 本表标注了「本机覆盖」的条目，就是 `config.kdl` 里改掉了 `base.kdl` 默认值的那几条。

## 最常用

| 按键          | 作用                                           |
| ------------- | ---------------------------------------------- |
| `Mod+T`       | 终端 kitty                                     |
| `Mod+D`       | 启动器 fuzzel（输名字也能当文件/应用搜索用）   |
| `Mod+Q`       | 关闭当前窗口                                   |
| `Mod+O`       | 概览（所有工作区缩略图，鼠标甩左上角也能触发） |
| `Mod+Shift+/` | niri 内置「重要快捷键」浮层                    |
| `Mod+/`       | 本速查表（浮动窗口）                           |

## 焦点与移动

| 按键                             | 作用                                     |
| -------------------------------- | ---------------------------------------- |
| `Mod+←/↓/↑/→`                    | 焦点移到 左 / 下 / 上 / 右               |
| `Mod+H/J/K/L`                    | 同上（vim 风格：H 左、J 下、K 上、L 右） |
| `Mod+Ctrl+←/→` 或 `Mod+Ctrl+H/L` | 把**整列**往左 / 右挪                    |
| `Mod+Ctrl+↓/↑` 或 `Mod+Ctrl+J/K` | 把**单个窗口**往下 / 上挪                |
| `Mod+Home` / `Mod+End`           | 焦点跳到第一列 / 最后一列                |
| `Mod+Ctrl+Home` / `Mod+Ctrl+End` | 把当前列移到最前 / 最后                  |

> niri 是「列」式平铺：`Mod+←/→` 换列，`Mod+↑/↓` 在列内换窗口。
> 列里的窗口上下堆叠，`Mod+W` 可以改成标签页式。

## 工作区（动态，用完即回收）

| 按键                                        | 作用                                             |
| ------------------------------------------- | ------------------------------------------------ |
| `Mod+Page_Up` / `Mod+Page_Down`             | 上一个 / 下一个工作区                            |
| `Mod+I` / `Mod+U`                           | 同上（I 上、U 下）                               |
| `Mod+1..9`                                  | 直接跳到工作区 1–9                               |
| `Mod+Ctrl+Page_Up` / `Mod+Ctrl+Page_Down`   | 把当前列移到上 / 下工作区                        |
| `Mod+Ctrl+I` / `Mod+Ctrl+U`                 | 同上                                             |
| `Mod+Ctrl+1..9`                             | 把当前列移到工作区 1–9                           |
| `Mod+Shift+Page_Up` / `Mod+Shift+Page_Down` | 工作区整体上移 / 下移                            |
| `Mod+Shift+I` / `Mod+Shift+U`               | 同上                                             |
| `Mod+Shift+Home` / `Mod+Shift+End`          | 把当前工作区顶到最上 / 最下（向上/下连移 32 次） |
| `Mod+滚轮上/下`                             | 切工作区（150ms 冷却，防止一滑到底）             |

## 窗口与布局

| 按键                                   | 作用                                             |
| -------------------------------------- | ------------------------------------------------ |
| `Mod+R` / `Mod+Shift+R`                | 循环预设列宽 / 反向循环                          |
| `Mod+Minus` / `Mod+Equal`              | 列宽 −10% / +10%                                 |
| `Mod+Shift+Minus` / `Mod+Shift+Equal`  | 行高 −10% / +10%（列内多窗口时生效）             |
| `Mod+Ctrl+R`                           | 重置行高                                         |
| `Mod+Ctrl+Shift+R`                     | 切换预设行高                                     |
| `Mod+F`                                | 列最大化（保留间隙和边框）                       |
| `Mod+M`                                | 窗口最大化到屏幕边缘（无间隙，相当于双击标题栏） |
| `Mod+Shift+F`                          | 窗口全屏（盖住状态栏）                           |
| `Mod+Ctrl+F`                           | 把列撑满剩余空间                                 |
| `Mod+C` / `Mod+Ctrl+C`                 | 居中当前列 / 居中所有可见列                      |
| `Mod+W`                                | 列的「标签页」显示模式开关（竖排 tab，不叠放）   |
| `Mod+BracketLeft` / `Mod+BracketRight` | 把窗口吞进左 / 右侧相邻列，再按则吐出            |
| `Mod+Comma` / `Mod+Period`             | 把右列窗口吞进本列底部 / 把本列底部窗口吐到右边  |
| `Mod+V`                                | 当前窗口 浮动 ↔ 平铺 切换                        |
| `Mod+Shift+V`                          | 焦点在浮动窗口与平铺窗口之间来回切               |
| `Mod+滚轮左/右`                        | 焦点左 / 右列                                    |
| `Mod+Ctrl+滚轮左/右`                   | 列左 / 右移                                      |
| `Mod+Shift+滚轮上/下`                  | 焦点左 / 右列（等价于应用内的横向滚动）          |
| `Mod+Ctrl+Shift+滚轮上/下`             | 列左 / 右移                                      |

## 多显示器

| 按键                     | 作用                                |
| ------------------------ | ----------------------------------- |
| `Mod+Shift+←/↓/↑/→`      | 焦点切到左 / 下 / 上 / 右显示器     |
| `Mod+Shift+H/J/K/L`      | 同上                                |
| `Mod+Shift+Ctrl+←/↓/↑/→` | 把当前列移到左 / 下 / 上 / 右显示器 |
| `Mod+Shift+Ctrl+H/J/K/L` | 同上                                |

## 截图

| 按键                       | 作用                                     |
| -------------------------- | ---------------------------------------- |
| `Mod+P`                    | 截图界面（拖拽选区 / 点窗口 / 回车全屏） |
| `Mod+Ctrl+P`               | 直接截整屏                               |
| `Mod+Alt+P`                | 直接截当前窗口                           |
| `Print`                    | 同 `Mod+P`                               |
| `Ctrl+Print` / `Alt+Print` | 同 `Mod+Ctrl+P` / `Mod+Alt+P`            |

> 三组 `Mod+P` 是**本机覆盖**：75% 配列没有独立 PrtSc 键，而 `Mod+Shift+P` 已被
> `base.kdl` 用作关闭显示器，所以取无修饰 / Ctrl / Alt 三个组合。
> 保存位置：`~/Pictures/Screenshots/prtScr-%Y%m%d-%H%M%S.png`，同时进剪贴板。
> niri 自带截图，不依赖 grim / spectacle / portal。

## 声音、亮度、媒体

| 按键                                       | 作用                                    |
| ------------------------------------------ | --------------------------------------- |
| `XF86AudioRaiseVolume` / `...LowerVolume`  | 音量 ±4%（**本机覆盖**，默认是 ±10%）   |
| `XF86AudioMute`                            | 静音开关                                |
| `XF86AudioMicMute`                         | 麦克风静音开关                          |
| `XF86AudioPlay` / `Stop` / `Prev` / `Next` | playerctl 播放 / 停止 / 上一首 / 下一首 |
| `XF86MonBrightnessUp` / `...Down`          | 亮度 ±10%                               |

> 音量/亮度键带 `allow-when-locked=true`，锁屏状态下也能用。

## 会话与电源

| 按键              | 作用                                                       |
| ----------------- | ---------------------------------------------------------- |
| `Ctrl+Alt+Delete` | noctalia 会话面板（关机 / 重启 / 注销 / 锁屏）**本机覆盖** |
| `Super+Alt+L`     | 锁屏 swaylock，解锁需输密码                                |
| `Mod+Shift+P`     | 关闭显示器（动鼠标或按任意键恢复）                         |
| `Mod+Shift+E`     | 退出 niri（会有确认对话框）                                |
| `Mod+Escape`      | 切换「键盘快捷键拦截」——远程桌面 / 软件 KVM 抢键盘时用     |

> `base.kdl` 里 `Ctrl+Alt+Delete` 原本是「退出 niri」，本机改成了会话面板；
> 要退出 niri 请用 `Mod+Shift+E`。

## 其他

| 按键          | 作用                                                |
| ------------- | --------------------------------------------------- |
| `Super+Alt+S` | 屏幕阅读器 orca 开关（一般用不到）                  |
| `Mod+N`       | **未绑定**（浏览器那条已解绑，见 `config.kdl`）     |
| `Mod+E`       | **未绑定**（`config.kdl` 里注释掉了文件管理器那条） |

> 文件管理器可以用 `Mod+D` 打开 fuzzel 输 `dolphin`，或者终端里 `xdg-open ~`。

## 鼠标 / 触摸板

| 操作               | 作用                   |
| ------------------ | ---------------------- |
| `Mod` + 左键拖窗口 | 移动窗口（平铺也支持） |
| `Mod` + 右键拖     | 调整窗口大小           |
| `Mod` + 中键       | 同左键拖               |
| 四指上滑（触摸板） | 打开概览               |
| 鼠标甩到屏幕左上角 | 打开概览（热区）       |

> 窗口边框可拖拽调整尺寸；双击标题栏 = 最大化到边缘（同 `Mod+M`）。
